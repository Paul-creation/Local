# 최대 인원 판단 규칙

기준: 친구끼리 한 판에 같이 할 수 있는 최대 인원. 모드·비공식 패치는 제외하고 공식 기능만 본다. AI API는 쓰지 않고 직접 판단한다.

1. 공개 서버·로비형 게임(GTA V, BF V, 배너로드, 레이싱 등): 친구들이 같은 세션·로비에 함께 들어갈 수 있는 공식 최대 인원을 쓴다.
   - **서버형은 설정을 바꾸지 않고 기본 설정으로 바로 되는 인원 기준** (Project Zomboid 32, Terraria 16).
   - 16명을 넘으면 DB에는 실제 숫자를 저장하고, 화면에는 "16명+"로 표시한다 (app/lib/players.ts).
2. 비공식 근거만 있으면 독립된 출처 2곳 이상이 같은 숫자일 때만 채우고, 출처를 이 폴더에 기록한다.
3. 모드마다 다르면 본편의 기본 멀티 모드를 기준으로 한다.
   - 침입·난입처럼 적으로 들어오는 인원은 빼고 센다. 소울류는 호스트 + 소환 협력자 수 (DARK SOULS REMASTERED·III 모두 마른 손가락 사용 시 4명, 스팀의 "6명"은 침입자 2명 포함).
4. 위 규칙으로도 정할 수 없으면 null로 둔다 (화면에는 "인원 정보 확인 중").

반영 도구: `node --env-file=.env.local scripts/apply-verified-players.mjs <결정 파일>`. 반영 기록은 applied-log.txt에 쌓인다.

기록 위치: 검증 결과 요약(게임·근거·결론)은 `docs/verification/`에 md로 남기고, 결정 파일·원본 데이터만 `data/verification/`(커밋 안 됨)에 둔다.

# 혼자 플레이 단계·팀/서버 인원 (data/meta/play-modes.json)

최대 인원(min/max_players)과 별개로, 게임마다 아래 세 칸을 둔다. AI API는 쓰지 않고 직접 판단하며, 확신이 없으면 null.

## solo — 혼자 플레이 단계

| 값 | 기준 | 화면 문구 |
|---|---|---|
| `story` | 멀티 요소가 없거나 혼자가 중심. 1인 전용 게임은 모두 여기 | 혼자 해도 충분해요 |
| `possible` | 친구 없이도 즐길 수 있음. 온라인 매칭(PvP 포함)·MMO처럼 혼자 접속해서 할 수 있거나 봇·싱글 모드가 있음 (예: 딥 락 갤럭틱, 리썰 컴퍼니, LoL, PUBG, 어몽 어스) | 혼자도 가능 |
| `none` | 파트너가 꼭 있어야 하는 게임만. 2인 전용 협동, 매칭 없이 친구 초대로만 하는 게임 (예: 잇 테이크스 투) | 멀티 전용 |
| `null` | 판단 보류 | (표시 안 함) |

- 기준 한 줄: "친구 없이도 즐길 수 있으면 possible". `solo_playable`은 `solo_mode`에서 파생 (story·possible → true, none → false)
- 기존 게임 전체 재판정: `judge-new-games.mjs --rejudge` (미리보기) → `--rejudge --apply`
- 근거: 스팀 태그(Singleplayer·Story Rich와 멀티 관련 태그의 투표 비율), 한 줄 소개의 "혼자" 표현, 게임을 아는 범위의 판단
- 스팀 태그에 멀티 관련 태그가 하나도 없으면 1인 전용으로 보고 `story` (게임이 아닌 프로그램은 null)
- 매주 새로 들어온 게임은 `scripts/judge-new-games.mjs`가 이 기준(진입장벽은 data/tags/entry-barrier.json의 rule)으로 Haiku에 물어 채운다. 빈 칸만 채우고, 확신 없으면 null. party_max·session_max는 채우지 않는다

## party_max — 친구끼리 같이 할 수 있는 최대 인원 (팀·파티)

- 기본: 친구끼리 한 팀·파티로 묶일 수 있는 최대 인원 (예: 레데리2 포스 7, GTA 온라인 조직 8, 배틀로얄 스쿼드 4)
- 예외: 커스텀·사설 매치로 친구끼리 양 팀을 채워 내전하는 게 기본 기능인 대전 게임은 **양 팀 합계** (예: LoL·오버워치 2·CS2·발로란트·시즈·SMITE·팔라딘스·히오스 10, 로켓 리그 8, TF2 24, 데바데 5 = 생존자 4 + 살인마 1)
- 팀 개념이 없이 한 월드·서버에 다 같이 들어가는 게임은 `session_max`와 같은 값 (예: 테라리아 16, 프로젝트 좀보이드 32)

## session_max — 같은 서버·세션 최대 인원

- 같은 서버·로비·한 판에 함께 있을 수 있는 공식 최대 인원 (예: 레데리2 32, GTA 온라인 30, PUBG 100)
- 서버형은 위 최대 인원 규칙처럼 **설정을 바꾸지 않은 기본 설정** 기준. 서버마다 크게 다르면 null (예: 러스트)

## 채우는 범위

- `party_max`·`session_max`는 서버형·대전형처럼 "같은 판 인원"과 "친구끼리 묶이는 인원"이 다른 게임만 채우고, 나머지는 null
- `game_id`를 아직 모르는 새 게임은 `game_id: null`, `steam_appid`로 적는다 (반영 스크립트가 앱 번호로 찾음)
