# 디자인 원칙

화면에 보이는 문구는 한국어로 쓴다. 색 값은 `app/globals.css`의 토큰으로만 쓴다.

## 아이콘

- 아이콘은 **찜·비교 버튼의 SVG 아이콘만** 허용한다.
- 이모지, ▶, 화살표, 장식용 아이콘은 계속 금지한다.

## 색

기존 토큰 외에 상태를 나타내는 색 토큰은 아래 네 가지만 쓴다. **이 밖의 새 색은 금지**한다.

| 토큰 | 용도 | 비고 |
| --- | --- | --- |
| `--wishlist-active` | 찜 활성(빨강) | |
| `--steam-buy` | 스팀 구매 버튼(초록) | 플랫폼 색 예외는 이 버튼만 허용 |
| `--compare-active` | 비교 활성(파랑) | |
| `--verdict-fail` | PC 판정 미달(빨강) | |

### 포인트색(`--accent`, #66C0F4) 용도

기본 버튼·슬라이더·포커스·선택된 칩·TOP 10·운영자 배지·**추천도 게이지 채움**. 게이지의 빈 칸은 `--border` 토큰을 쓴다.

## 칩

- 칩은 사이트 전체에서 **공통 `.chip` 스타일 하나만** 쓴다. 페이지마다 따로 칩을 정의하지 않고, 색·라운딩·hover를 덮어쓰지 않는다.
- 선택 상태는 `.chip.on` 또는 `aria-pressed="true"`로 표시한다.

## PC 판정 표시

- PC 판정은 **상세 페이지의 사양 카드에만** 표시한다. 카드 목록에는 넣지 않는다.
- 성능이나 프레임을 단정하는 문구("쾌적하게 돌아감", "60fps 가능" 등)는 쓰지 않는다.

## 글자

- 보조 글자는 **최소 13px**로 한다.
- 흐리게 보이려고 `opacity`를 쓰지 않고, 서브 텍스트 토큰(`--text-2`, `--text-muted`, `--text-faint`)을 쓴다.
