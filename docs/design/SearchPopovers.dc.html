공통 규칙

1팝오버는 z-index 40, 결과 카드·괄호·sticky 요소보다 항상 위 (괄호가 팝오버 위로 비치면 안 됨)
2팝오버 위치: 연 칸의 왼쪽 아래 12px, 화면 오른쪽을 넘으면 오른쪽 맞춤
3열린 칸은 흰 배경 대신 살짝 밝은 회색(#2A2925) + 안쪽 테두리
4선택 표시는 크림 채움만, 괄호 없음
5여러 개 선택 시 칸 값은 "공포 외 1개" (말줄임 "공포, ..." 금지)
6바깥 클릭·Esc로 닫힘, 결과는 "적용/N개 보기"를 눌렀을 때 바뀜
7모바일(768px 이하)에서는 팝오버 대신 아래에서 올라오는 시트(전체 폭)
