# 디자인 원칙

- 화면에 보이는 문구는 한국어로 쓴다. 색 값은 app/globals.css의 토큰으로만 쓴다.
- 다크 고정(라이트 모드 없음). 포인트 색 #66C0F4는 hover 테두리, 타이틀, 주요 버튼, 특별 칩, 추천도 게이지, 진행 바, 슬라이더, 포커스, 선택된 칩, TOP 10, 운영자 배지에 쓴다. 새 용도를 추가하려면 먼저 확인받는다.
  - 진행 바는 헤더 바로 아래 2px, 그림자·발광·깜빡임 없음, 움직임 줄이기 설정이면 애니메이션 없이 표시만. 추천도 게이지의 빈 칸은 --border.
- 새 색 금지. 상태 색 토큰만 쓴다: --up(초록), --down/--sale(산호 빨강), --review, --text-muted. 상태 색은 유불리 정보에만 쓴다. 할인 칸 초록은 현행 유지. 금색 토큰은 관리자 화면 전용.
  - 상태 색과 별개로 아래 기능 토큰은 해당 용도로만 쓴다: --wishlist-active(찜 활성, 빨강), --steam-buy(스팀 구매 버튼, 초록 — 플랫폼 색 예외는 이 버튼만), --compare-active(비교 활성, 파랑), --verdict-fail(PC 판정 미달, 빨강).
- 아이콘은 찜·비교 SVG만 쓴다. 나머지는 텍스트 문자(← → ‹ ›). 이모지·▶·장식용 아이콘은 금지.
- 금지: 노랑·주황·금색, 글래스모피즘(비교 하트만 예외), 네온, 깜빡임.
- 부드러운 이동은 허용하되 prefers-reduced-motion이면 끈다.
- 로딩은 정지된 틀만 쓴다. shimmer(빛이 지나감)·pulse(깜빡임) 금지. 틀은 실제 화면과 같은 위치·크기에 --card/--inset 토큰으로 그리고, 로딩이 200ms 안에 끝나면 틀을 보이지 않게 한다(번쩍임 방지).
- 칩은 공통 .chip 하나만 쓴다. 페이지마다 따로 정의하지 않고 색·라운딩·hover를 덮어쓰지 않는다(크로스플레이·한국어 미지원 칩의 --up/--down 색은 상태 색 원칙에 따른 예외). 선택 상태는 .chip.on 또는 aria-pressed="true".
- 보조 글자는 13px 이상. 흐리게 보이려고 opacity를 쓰지 않고 서브 텍스트 토큰(--text-2, --text-muted, --text-faint)을 쓴다.
- PC 판정은 상세 페이지의 사양 카드에만 표시하고 카드 목록에는 넣지 않는다. 성능이나 프레임을 단정하는 문구("쾌적하게 돌아감", "60fps 가능" 등)는 쓰지 않는다.
- 통일 게임 카드 순서: 이름 → 인원·진입장벽 → Steam 평가 단독 줄(등급 문구가 주, %는 보조) → 칩(GOTY·태그 2·크로스플레이·한국어 미지원) → 가격 하단 고정.
- 접기는 .is-collapsed + "더 보기" 패턴, 모바일 가로 줄은 인원별 추천의 가로 스크롤 패턴을 재사용한다.
- 기각된 것(다시 제안하지 않기): 노랑 신호등, GOTY 금색 배지, 배너 캐러셀, 100vh 고정, 카드 동접 그래프, 1~3위 동접 숫자, "구동 불가" 배지, 카드 목록 판정 표시, 예상 FPS·벤치마크 점수.
