# 디자인 원칙

- 다크 기본. 포인트 색 #66C0F4는 hover 테두리, 타이틀, 주요 버튼, 특별 칩, 추천도 게이지, 진행 바에만 쓴다.
- 새 색 금지. 상태 색 토큰만 쓴다: --up(초록), --down/--sale(산호 빨강), --review, --text-muted. 상태 색은 유불리 정보에만 쓴다. 할인 칸 초록은 현행 유지. 금색 토큰은 관리자 화면 전용.
- 아이콘은 찜·비교 SVG만 쓴다. 나머지는 텍스트 문자(← → ‹ ›).
- 금지: 노랑·주황·금색, 글래스모피즘(비교 하트만 예외), 네온, 깜빡임.
- 부드러운 이동은 허용하되 prefers-reduced-motion이면 끈다.
- 로딩은 정지된 틀만 쓴다.
- 칩은 공통 .chip을 쓴다. 보조 글자는 13px 이상.
- 통일 게임 카드 순서: 이름 → 인원·진입장벽 → Steam 평가 단독 줄(등급 문구가 주, %는 보조) → 칩(GOTY·태그 2·크로스플레이·한국어 미지원) → 가격 하단 고정.
- 접기는 .is-collapsed + "더 보기" 패턴, 모바일 가로 줄은 인원별 추천의 가로 스크롤 패턴을 재사용한다.
- 기각된 것(다시 제안하지 않기): 노랑 신호등, GOTY 금색 배지, 배너 캐러셀, 100vh 고정, 카드 동접 그래프, 1~3위 동접 숫자, "구동 불가" 배지, 카드 목록 판정 표시, 예상 FPS·벤치마크 점수.
